# Conformance

**Vectors** (`jcs.json`, `capacity.json`, `remit_id.json`, `sql.json`): any
implementation of the core must reproduce the valid cases and reject the invalid
ones with the listed code. They are generated by the TypeScript oracle
(`node scripts/gen-conformance.ts`) and checked by Rust, TypeScript, Python and Go.

**Black-box Holder suite**: `remit conformance <url> --identity <file> [--program <file>]`.
It needs one identity the Holder trusts and one admissible program (the catalog's
first example by default), and checks envelope handling, authentication,
freshness and replay, the SQL profile, result types, counter-offers, blobs,
asynchronous runs, receipts and their bindings, transparency proofs, kernel
containment, and the MCP / A2A / Connect bindings. `scripts/conformance.sh` runs
it against the example Holders.
